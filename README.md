## 🎯 نظرة عامة

نظام متكامل لمطابقة قوائم الحسابات وتحليل القوائم المالية وفق معايير IFRS/IAS 1. يقارن بين فترتين ماليتين، يحسب 31 نسبة مالية عبر 5 مجموعات، يُصدّر تقارير PDF/CSV/Excel احترافية، ويعرض تنبيهات ذكية للعتبات الحرجة.

## ✨ الميزات الرئيسية

### 📋 مطابقة قوائم الدخل (IAS 1 — طريقة الوظيفة)
- مقارنة فترتين: الحالية مقابل المقارنة
- وضع الشهر مقابل التراكمي (نسبة الشهر من السنة)
- مطابقة دليل الحسابات (بالاسم أو الرقم)
- بادئات قابلة للتخصيص (تكلفة الإيرادات، البيع، الإدارية، تشغيلية أخرى، التمويل، ضريبة الدخل، الدخل الشامل الآخر)

### 💰 قوائم المركز المالي
- رفع ملفات قائمة المركز المالي (اختياري)
- حساب 31 نسبة مالية موزعة على 5 مجموعات:
  - **نسب السيولة** (5 نسب: التداول، السريعة، النقدية، الفاصل الدفاعي، رأس المال العامل)
  - **نسب المديونية والرفع المالي** (8 نسب)
  - **نسب الربحية** (8 نسب: الهوامش، ROA، ROE، DuPont)
  - **نسب النشاط والكفاءة** (6 نسب: دوران الأصول، المخزون، المدينين، الدائنين)
  - **فترات التحصيل والسداد (بالأيام)** (4 نسب: DIO، DSO، DPO، CCC)

### 🧠 التحليل الذكي
- **ملخص تنفيذي تلقائي**: الوضع العام، أبرز تحسّن، أبرز تراجع، أقوى/أضعف مجال
- **تنبيهات ذكية**: 10 عتبات حرجة (نسبة التداول <1×، المديونية >70%، تغطية الفوائد <1.5×، صافي الربح سالب، إلخ)
- **شارات الحالة**: ممتاز ✅ / مقبول ⚠️ / ضعيف ❌ حسب المعايير المرجعية
- **شريط صحة المجموعة**: نسبة تحقيق المعايير لكل مجموعة
- **تفسير تلقائي لكل نسبة**: "ممتاز — يحقق المعيار المرجعي (125% منه)"
- **شرح مبسّط**: لكل نسبة جملة عربية تشرح معناها

### 🤖 التحليل الذكي المعزّز (جديد — GLM-5.3-Flash)
- **تحليل AI احترافي** للنسب المالية بنموذج **GLM-5.3-Flash** (تمت الترقية من GLM-5.2): أسرع استجابة ودقة أعلى في المصطلحات المالية العربية
- **بث مباشر** للتقرير أثناء توليده (ملخص تنفيذي، تحليل حسب المجموعات، نقاط القوة، المخاطر والملاحظات، توصيات عملية قابلة للتنفيذ)
- **زر نسخ** للتقرير و**إعادة توليد** فورية
- يعمل مباشرة من تبويب «التحليل المالي» بمجرد وجود بيانات المركز المالي

### 📊 التصور البصري
- رسوم بيانية تفاعلية (Chart.js)
- Sparklines مصغّرة لكل نسبة
- شريط تقدّم نحو المعيار المرجعي
- شارات التغير ملوّنة (أخضر/أحمر حسب المرغوبية)

### 📤 التصدير
- **PDF** بصفحة غلاف احترافية + أرقام صفحات + فواصل ذكية
- **CSV** مع دعم BOM للعربية في Excel
- **Excel** متعدد الأوراق (البيانات + التحليل + الصيغ)

### 🎨 تجربة المستخدم
- **بحث وفلترة** بالنص أو الحالة (ممتاز/ضعيف)
- **وضع ليلي/نهاري** مع حفظ التفضيل
- **دعم اللغتين** العربية والإنجليزية (Toggle)
- **اختصارات لوحة المفاتيح**: `/` للبحث، `Esc` للمسح، `t` للوضع الليلي، `a` للتنبيهات
- **تصميم متجاوب** (mobile-first)
- **PWA-friendly** (theme-color, viewport-fit)

### 🔐 الأمان والصلاحيات
- مصادقة NextAuth.js مع JWT
- نظام صلاحيات: admin / user
- صلاحيات قابلة للتخصيص لكل مستخدم (view, add, edit, delete, groups, export, settings, manageUsers)
- إدارة المستخدمين (admin only)

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js 18+ أو Bun
- npm / bun

### الخطوات
```bash
# 1. تثبيت التبعيات
bun install   # أو npm install

# 2. إعداد قاعدة البيانات
bun run db:push

# 3. تشغيل خادم التطوير
bun run dev   # http://localhost:3000

# 4. إنشاء المستخدم admin الأول (عبر /api/setup أو التطبيق)
# عند فتح التطبيق لأول مرة، سيُطلب منك إنشاء حساب المدير

# 5. فحص الكود
bun run lint
```

### بيانات الدخول الافتراضية
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`

> ⚠️ **تنبيه**: غيّر كلمة المرور الافتراضية فور تسجيل الدخول لأول مرة في بيئة الإنتاج.

## 📖 كيفية الاستخدام

### مطابقة قوائم الدخل
1. اختر الوضع: "الفترة الحالية مقابل السابقة"
2. ارفع ملفي Excel (الفترة المقارنة + الفترة الحالية)
3. حدد بادئات بنود القائمة (IAS 1)
4. اختر حساب صافي الإيرادات الأساسي
5. اضغط "بدء المطابقة"

### التحليل المالي
1. ارفع ملفي قائمة المركز المالي (اختياري)
2. افتح تبويب "التحليل المالي"
3. استكشف: الملخص التنفيذي ← التنبيهات الذكية ← النسب حسب المجموعة
4. ابحث أو فلتر بالنص أو الحالة
5. صدّر التقرير (PDF/CSV/Excel)
